What this is

Little SQL is a small database engine written from scratch: a reader for the SQLite file format, B-tree traversal, a SQL parser, a query planner that uses indexes, and an executor for joins, grouping, ordering, aggregates and subqueries. It has no dependencies. This page runs it as WebAssembly in a web worker.

Each query shows its query plan: which table or index every loop reads, how many times the loop ran and how many rows it visited. The words are SQLite's own (SCAN, SEARCH … USING INDEX), and on the project's planner test set the plans are identical to SQLite's.

Your data stays here

A database you open is read in your browser and never uploaded anywhere. Little SQL can open SQLite files of any page size and text encoding; files that use features it does not support yet will say so.

The demo database

Every HDB resale flat transaction in Singapore registered from January 2022 to November 2026: tables resale and towns, and a view sales that joins them.

Contains information from Resale flat prices based on registration date from Jan-2017 onwards, accessed on 12 November 2026 from data.gov.sg, which is made available under the terms of the Singapore Open Data Licence version 1.0.
